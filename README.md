# Green-space-accessibility
QUIS and ARCGIS tool used to measure correlation between access to measure how accessibility to public green space vary across socioeconomic groups in UK cities?

## Project Goal

This project aims to answer:

> "How access to public greenspace correlates with socioeconomic situations"

The project combines open spatial datasets with GIS analysis to produce maps and insights suitable for a professional portfolio.

I'm building this project to strengthen my GIS portfolio while learning ArcGIS Online alongside Python-based geospatial analysis.
